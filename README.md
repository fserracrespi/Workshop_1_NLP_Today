# NLP — Session 1: POS Tagging and Syntactic Parsing

## Overview

This project introduces two fundamental Natural Language Processing tasks:

1. **Part-of-Speech (POS) Tagging**
2. **Syntactic Parsing using the CYK algorithm**

The main objective is to compare different POS tagging approaches and analyse how POS annotations and grammar rules affect syntactic parsing.

---

## Part 1 — POS Tagging

### Phase 1 — Dataset

The dataset contains sentences from both **general** and **specific scientific domains**.

#### General Domain

* The cat sat on the couch.
* Time flies like an arrow.
* The spy saw the cop with the telescope.
* The spy saw the cop with the revolver.

#### Specific Domain

**Biology**

* Arabidopsis thaliana seedlings exhibit longer hypocotyls when they are grown under high ambient temperature, which is defined as thermomorphogenesis.

**Astronomy**

* A spectrogram of PSN J10354824+3900279 obtained on Dec. 19.33 UT suggests that this is a type-Ia at redshift z 0.044.

---

### Phase 2 — Manual POS Annotation

Each sentence is manually annotated using a reduced version of the **Universal POS tagset**.

The allowed POS tags are:

```text
ADJ
ADP
AUX
DET
NOUN
NUM
PROPN
PUNCT
SCONJ
VERB
```

The manual annotations are used as the **gold standard** for model evaluation.

Reference:

https://universaldependencies.org/u/pos/

---

### Phase 3 — Automatic POS Tagging

The sentences are annotated automatically using different NLP models.

#### spaCy

Installation:

```bash
pip install -U spacy
python -m spacy download en_core_web_sm
```

Example:

```python
import spacy

nlp = spacy.load("en_core_web_sm")

doc = nlp("The cat sat on the couch.")

for token in doc:
    print(token.text, token.pos_)
```

#### sciSpaCy

sciSpaCy is designed for scientific and biomedical text and will be used to compare its performance with general-purpose spaCy models.

Installation:

```bash
pip install scispacy
```

---

### Phase 4 — POS Evaluation

The automatic predictions are compared against the manually annotated gold standard.

The evaluation includes:

* Accuracy per sentence
* Overall accuracy
* Correct POS predictions
* Incorrect POS predictions
* Most common POS errors
* Comparison between general and scientific domains

Workflow:

```text
Sentence
   ↓
Manual POS Annotation
   ↓
Gold Standard
   ↓
┌───────────────┐
│               │
spaCy        sciSpaCy
│               │
└───────┬───────┘
        ↓
    Evaluation
```

The results are used to discuss the **strengths and weaknesses** of each approach.

# Part 2 — Syntactic Parsing

## Phase 5 — Context-Free Grammar

A **Context-Free Grammar (CFG)** is defined to describe the syntactic structure of the sentences.

The allowed non-terminal phrases are:

```text
NP → Noun Phrase
VP → Verb Phrase
PP → Prepositional Phrase
```

Example grammar:

```text
S → NP VP

NP → DET NOUN

VP → VERB PP

PP → ADP NP
```

The grammar may need to be modified depending on the POS annotations and the structure of each sentence.

---

## Phase 6 — CYK Parsing

The **Cocke–Younger–Kasami (CYK)** algorithm is used for constituency parsing.

The algorithm determines whether a sequence can be generated by the defined grammar and produces the corresponding syntactic structure.

Workflow:

```text
Sentence
   ↓
POS Tags
   ↓
Context-Free Grammar
   ↓
CYK Algorithm
   ↓
Constituency Tree
```

Provided implementation:

https://thomas-gerald.fr/TMC/resources/cyk.py

---

## Phase 7 — Syntactic Ambiguity

Some sentences can have more than one valid syntactic interpretation.

Example:

```text
The spy saw the cop with the telescope.
```

The phrase:

```text
with the telescope
```

can be interpreted as being associated with:

```text
the cop with the telescope
```

or with the action:

```text
saw ... with the telescope
```

Different POS annotations and grammar rules can therefore produce different constituency trees.

The objective is to analyse how the following factors affect parsing:

* POS annotations
* Context-Free Grammar rules
* Sentence ambiguity

---

## Phase 8 — Comparison with Existing Parsers

The CYK results are compared with an existing constituency parser.

Possible tools:

* spaCy syntactic analysis
* Berkeley Neural Parser

Berkeley Parser:

https://parser.kitaev.io/

The objective is to compare automatically generated syntactic structures with those obtained using the manually defined CFG and CYK algorithm.
